# Glosario técnico del proyecto

Este glosario explica términos usados por los contratos y herramientas locales.
Las definiciones describen el software y no constituyen una interpretación legal.
Los nombres exactos de campos se conservan en inglés para encontrarlos en el código.

| Término | Significado en el proyecto |
|---|---|
| as_of | Instante explícito que limita el conocimiento elegible en 011 |
| Cohorte | Universo declarado de hechos de un scope; no se amplía silenciosamente |
| Cobertura | Estado del universo y conteo esperado respaldados por un manifiesto |
| Evidencia | Referencia a bytes preservados, fuente, extracción y versión de adaptador |
| Revisión | Versión numérica de una observación de una fuente y clave |
| Tombstone | Revisión que retira una clave sin resucitar una versión anterior |
| PASS | La regla fue evaluable y no cruzó su comparador |
| SIGNAL | La regla fue evaluable y cruzó su umbral exploratorio |
| NOT_EVALUABLE | No se cumplen las condiciones necesarias para calcular la regla |
| INVALID | Se detectó una contradicción o invalidez del alcance o de los hechos |
| BatchInvalid | Rechazo global de la entrada; no contiene evaluaciones parciales |
| Shadow | Ejecución privada separada de la historia y publicación de 004 |
| Spool | Contingencia de archivos para registros cosechados pendientes de sincronizar |
| MPA | Páginas HTML diferenciadas servidas por rutas, sin router hash SPA |
| Corte presupuestal | Fecha oficial de una observación; no equivale a fecha de extracción |
